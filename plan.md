## Bloomora Labs Website Plan

**Goal:** Build a website that makes visitors **feel** something in under 10 seconds.

Style inspiration:

* Apple
* Raycast
* Linear
* Notion

---

# 1. Hero (100vh)

### Layout

Center aligned.

Large whitespace.

```
LOGO

Bloomora Labs

Every dream deserves
a chance to bloom.

Short description

[ Explore Products ]
```

### Typography

Heading

* Very large
* Bold
* 2 lines maximum

Description

* Max width: 600px
* Soft gray

Button

* White background
* Black text
* Rounded Full

Background

Off-white (#FAFAFA)

No gradients.

No illustrations.

# Design Rules

### Colors

Background

```
#FAFAFA
```

Cards

```
#FFFFFF
```

Text

```
#111111
```

Secondary

```
#6B7280
```

Accent

Only one.

Very soft green.

```
#22C55E
```

Only buttons.

---

### Radius

```
24px
```

Everywhere.

---

### Shadows

Very subtle.

Almost invisible.

---

### Animations

Fade up.

300ms.

No fancy animations.

---

### Images

None initially.

# Feeling

The visitor should think:

> "This company genuinely cares about helping people grow."

Not

> "This company builds software."

---

## Final structure

```
Hero

↓

Mission

↓

Products

↓

Philosophy

↓

Principles

↓

Open Source

↓

Footer
```

**Rule:** Every section should answer one question:

* **Hero:** Who are we?
* **Mission:** Why do we exist?
* **Products:** What do we build?
* **Philosophy:** What do we believe?
* **Principles:** How do we build?
* **Open Source:** What do we give back?
* **Footer:** How do people reach us?

If you execute this with **excellent typography, generous whitespace, and restrained styling**, the site will feel far more premium than one filled with gradients, illustrations, and animations.
